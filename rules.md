# Business rules: Klinik Harapan registration

Every rule has an ID. Cite the ID in commit messages and pull requests.

| ID | Rule |
|---|---|
| R1 | Every patient has one medical record number (RM-000000), given once and never reused. |
| R2 | The phone number is required, so the front desk can call the patient when the doctor is late. |
| R3 | Queue number is unique per year. |
| R4 | The birth date cannot be in the future. |
| R5 | Only fictional data is used in this project. |
