# Klinik Harapan: patient registration

The registration form used at the front desk of Klinik Harapan, a fictional clinic.
Course project for RME542 Health Information System Analysis and Design.

## How to open it
Double-click `index.html`; it opens in your browser. Nothing is saved: this is a prototype.

## Files
- `index.html`, `style.css`: the form
- `rules.md`: business rules R1–R5
- `CHANGELOG.md`: what changed in each version
- `ISSUES.md`: the first issues for the team
- `data/sample_patients.csv`: fictional test patients

## Data
All data in this project is fictional. Never add real patient data, passwords or keys.
